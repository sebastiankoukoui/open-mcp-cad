## Warum es das gibt

open-mcp-cad steht unter der AGPL-3.0. Damit das Projekt später **zusätzlich**
kommerziell lizenziert werden kann — etwa für Firmen, die ihre Änderungen
nicht offenlegen dürfen —, muss eine Stelle die nötigen Rechte an allem Code
halten. Ohne diese Zusage von allen Beitragenden ist eine spätere
Lizenzänderung nicht möglich: fremder Beitrag, fremdes Recht.

Das schränkt dich nicht ein. Dein Beitrag bleibt dein Werk, du darfst ihn
weiter verwenden, wie du willst.

zulässt.

Zustimmung. Bitte gib das im Pull Request an.
